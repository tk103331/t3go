四步开始

桌面端无需登录即可本地使用。只有跨网络访问时，才需要通过 Relay 建立中转。

01

启动桌面端

下载并打开 T3Go，选择本机上的一个项目目录。

02

新建 Thread

选择项目、Agent、模型和分支，然后输入第一条任务。

03

连接设备

在 Access 中开启配对，手机扫码或粘贴配对链接。

04

开始协作

桌面、手机与浏览器同步查看执行过程、Diff 和运行结果。

本机优先

项目和 Agent 留在你的机器上。局域网内可直接连接，不依赖云端服务。

跨网络 Relay

外出时通过账号与环境建立反向隧道，用户 Token 不会转发到桌面端。

多环境统一视图

一个客户端管理多个环境，会话、Provider 和用量按环境隔离展示。
